## 三、第 2 轮裁决（D1–D5）

### D1｜正反馈 → 重定义为「信息性确认」 ✅ 采用推荐 (a)

- **决策**：教学阶段的「正反馈」= **信息性确认**（"你这一步对，因为……"）+ **可见的进度推进**（节点点亮、掌握度百分比上升）。**禁止泛化表扬**（"很棒！""真厉害！"）。
- **理由**：Kluger & DeNisi 1996（607 效应量，平均 d=.41）发现 **>1/3 的反馈干预降低了绩效**；注意力从「任务」转向「自我」时效应转负。纯表扬是信息量最低、自我指向最高的反馈形式。Deci 1999：依随奖励削弱内在动机 d=−0.28~−0.40，但**正向言语反馈**提升自由选择行为 d=+0.33。
- **用户原需求仍满足**：需求 27「教学关卡也要提高熟练度，正反馈不可缺失」在 (a) 下成立——正向信号的载体从「夸你」变成「你确实前进了」。
- **实现约束**：UI 层需有显式的「本步为何正确」槽位，不能只渲染 ✅ 图标。
- **否掉的替代**：(b) 额外保留鼓励语；(c) 只给信息不给任何正向信号。

### D2｜掌握度拆成 `achieved` / `current` 双字段 ✅ 采用推荐 (a)

- **决策**：
  - `achieved`：**不衰减**，管解锁 / 成就 / 成长记录。达到即永久保留。
  - `current`：**按半衰期衰减**，管推荐、难度选择与 **RAG 检索门控**。
  - UI **双栏显示**，用户可同时看到「曾达到」与「现在还剩多少」。
- **理由**：
  1. 遗忘曲线稳健可复现（Murre & Dros 2015）。
  2. Soderstrom & Bjork 2015 明确指出**当前表现 ≠ 长期学习**；Roediger & Karpicke 2006 中重读组**自信更高但成绩更差**——单一不衰减的 100% 等于批量生产元认知误判。
  3. **新增理由（m00218）**：`current` 同时作为 RAG 检索门控变量（Progressive Context Revelation）——掌握度低于阈值时，检索层**物理排除答案块**，见下方 D6。
- **满足用户需求**：需求 2「掌握度要有详细的百分比」——(a) 给的是**两个**更有意义的百分比。
- **否掉的替代**：(b) 单一不衰减数字；(c) 单一衰减数字。

### D3｜门控只设在章末出口与高入度先修节点 ✅ 采用推荐 (a)

- **决策**：
  - **硬门控**只设在 ① **章节出口** ② **高入度先修节点**。
  - **关内允许「尝试—失败—再听讲解」**，失败也计入进度（不算白做）。
  - 需求 29「最终核验必须落到题目关卡」完整保留。
- **理由**：Sinha & Kapur 2021（53 研究 / 166 比较）：成人领域知识**「先问题后讲解」（PS-I）优于「先讲解后问题」**，g=0.36 [0.20, 0.51]。用户原方案「掌握度跨阈值才开始题目关卡」方向相反。Kulik 1990（108 项对照）：掌握学习正效应真实，但**增加学习时间**且自定进度程序**常降低课程完成率**。
- **否掉的替代**：(b) 每关都门控（原方案）；(c) 完全无门控。

### D4｜图为主导航 + 线性退路 + 可解释推荐 ✅ 采用推荐 (a)

- **决策**：
  1. **图为主导航**（满足需求 9「不按章节组织」）。
  2. **同时保留一条线性主线**作为退路。
  3. **每次自动推荐都显示「为什么推荐这个」**，并允许一键改道。
- **理由**：
  - 「图 vs 线性」**无对照实验**——ITS 元分析（Ma 2014）测的是整套系统，无法归因到图结构本身。
  - Harati 2021：用 ALEKS 一学期后学生**自我调节学习技能显著下降**（缺乏动机、系统复杂、惩罚过重、缺乏社会存在感）。系统越聪明，用户越不动脑。
  - Adjei 2016：数据推断的先修强度与教师问卷基本吻合 → 图结构本身可用，问题在**完全交出控制权**。
- **否掉的替代**：(b) 纯自适应图、路径完全由系统决定（原方案）；(c) 章节线性为主、图谱只做可视化。

### D5｜视频片段裁剪到纯讲解区间 ✅ 采用 **(a)**（用户改选，非我的推荐）

- **决策**：抽出的 B站/YouTube 片段**必须裁剪到纯讲解区间**，≤6 分钟，关键词标注而非逐字字幕。
- **适用范围收窄**：用户明确「**只要几门核心课程就可以**」——不需要覆盖全部 128 本教材对应的课程。裁剪是**离线一次性**工作，只对核心课程的精选视频做。
- **理由**：Sundararajan & Adesope 2020：与教学目标无关的「有趣细节」**确实损害学习**——UGC 视频的片头闲聊、花哨剪辑正是这类细节。Rey 2019（56 研究）：分段原则有稳定小到中等效应；Schneider 2018：信号/线索有效；Adesope & Nesbit 2012：**关键词标注优于逐字字幕**。
- **我原本推荐 (b)**（只做时间戳跳转不裁剪，成本低），用户否决——范围收窄后成本可接受。
- **否掉的替代**：(b) 只做时间戳跳转＋关键词标注；(c) MVP 不做视频。

### D6｜掌握度门控 RAG 检索（新增，来自 m00218 侦察）

- **决策**：知识库每个 chunk 带 `is_answer_chunk: true|false` 标记。检索时**按 `current` 掌握度在检索层物理过滤**：

  | `current` 掌握度 | 检索模式 | 模型能看到 |
  |---|---|---|
  | < 0.4 | `context_only` | 只有背景上下文，**答案块被排除** |
  | 0.4–0.7 | `prerequisite_first` | 提示、结构、定义脚手架 |
  | > 0.7 | `full_reveal` | 全部，含答案 |

- **理由**：**提示词让模型「别给答案」是无效的**——泄露率随模型能力增强而上升，模型越强越会压过抑制提示（[NLP-UnMask](https://github.com/Sanika0212/NLP-UnMask)）。必须在架构层（检索层）解决，不是在 prompt 层。
- **配套**：结构化输出强制 Socratic 形态（`visible_response` 必须以 `?` 结尾）；内部推理字段在展示前剥离。
- **注意**：NLP-UnMask 是低 star 个人项目，**只借鉴思路，不复制代码**（符合 OmniDev 代码复用可信度策略）。

### D7｜追问策略 = 显式状态机 + 八级求助阶梯（新增）

- **决策**：追问不能靠一段提示词，必须做成**显式状态机**，且每轮由**非 LLM 的策略核心**（只读可信学习者状态）设置**求助阶梯上限**，再由独立 LLM judge 校验。
- **理由**：[arXiv 2608.12292](https://arxiv.org/html/2608.12292) 的实测数据——第一轮 **43% 的诚实求助被错误拒绝**、合规率 54%；四轮修复后 0% / 100%。记录的经验曲线叫 **"over-help ladder"**：明显泄露解法 → 直接点出具体 bug → 过度引用通用事实 → …，每修一层暴露下一层。
- **关键教训**：**过度拒绝（over-blocking）比帮助不足危害更大**。第一轮的主要问题是该帮的忙也被拒了。
- **实现约束**：需要**模拟学生跑评测**（不用真人），按拒绝原因分类统计，不能只看总通过率。

### D8｜时序决策与对话生成解耦（新增）

- **决策**：两件不同的事分开做——
  - **「下一个教哪个知识点」** = 轻量策略（规则或学习的策略），输入是学习者状态摘要 + 先修图结构。
  - **「怎么教」** = LLM 苏格拉底式对话，对话结束**返回掌握度信号**给时序策略。
- **理由**：[arXiv 2606.11744](https://arxiv.org/pdf/2606.11744)：这两件事需要**不同种类的推理**，一个 LLM 同时做会两头都做不好。学到的时序策略优于启发式基线，也优于纯 LLM 导师。

### D9｜BKT 在 TypeScript 内自行实现（新增）

- **决策**：**自己写** BKT（Bayesian Knowledge Tracing），不引入 Python 侧车。
- **理由**：[pyBKT](https://github.com/CAHLR/pyBKT) 是 Berkeley 官方实现（EDM 2021 论文），但是 **Python 库**，与 Mastra/TypeScript 栈不兼容。BKT 只有 4 个参数（prior / learn / guess / slip，加 forget），**TypeScript 里手写不到 100 行**。
- **参考**：Corbett & Anderson 1995（BKT 原始论文）。若将来需要 DKT 或 IRT 再评估。

## 三·补｜新增裁决（D10–D11）

### D10｜所有面向用户展示的内容必须是中文 ✅ 用户明确要求

- **决策**：**一切用户可见文本为中文**。范围包括：
  - UI 文案、按钮、标签、空状态、错误提示、加载提示
  - AI 生成的一切内容：讲解、追问、解析、反馈、关卡题目与选项
  - 关卡内容、知识点名称、知识点描述
  - 日志与诊断信息中**面向用户展示**的部分
  - 图表坐标轴、图例、tooltip
- **不在范围内**（保持英文，遵循 AGENTS.md 既有技术规范）：
  - 代码标识符、类型名、函数名
  - 数据库表名与列名
  - 文件名与目录名
  - 提交信息（遵循项目既有规范）
  - 第三方库的原始报错（需在 UI 层包一层中文解释，而不是翻译原始堆栈）
- **实现约束**：
  1. **禁止硬编码中文字符串散落在组件里** —— 集中到一处文案资源（便于统一审校与后续扩展学科/语言）。
  2. **LLM 输出的语言必须在系统提示中强制约束**，且需有**校验**：生成内容若为英文需重试或标红。这一条要在评测里覆盖。
  3. 教材原文引用（PDF 摘录）**保持原文**，但周围的解释性文字用中文。
- **风险**：`deepseek-v4.1-flash` 在处理英文技术术语时可能中英混杂。需在提示中明确「专业术语首次出现可用「中文（English）」格式，之后只用中文」。

### D11｜需要「数据库展示」与「skill 库展示」两个页面 ✅ 用户明确要求

- **决策**：除智能体主页、看板页、知识图谱关卡页外，**必须有**：
  1. **数据库展示页**：可视化查看应用内数据（知识库、知识点、题目、作答记录、掌握度、学习日志）
  2. **skill 库展示页**：查看应用内置的全部 skill（名称、描述、触发条件、版本、所属层级）
- **定位**：这两个页面属于「浅色学术工作台」一侧，是**管理/检视**视图，不是学习流程的一部分。
- **对 D6 的意义**：数据库展示页是 D6（掌握度门控 RAG）的**可观测性前提**——用户能看到「为什么这次检索没给答案」，否则整个机制是黑盒。
- **对「skill 打包在应用里」的意义**：skill 库展示页是用户「方便管理和迁移」诉求的**落地界面**。skill 不是藏在代码里的常量，而是可浏览的一等资产。
- ⚠️ **两个页面的具体范围待裁决**（见 open-questions）。

## 三·补二｜新增裁决（D12–D13，来自 m00325）

### D12｜初始水平判定 + 流程分化（不做死板单一流程）✅ 用户明确要求

- **决策**：首次使用必须先**判定起始水平**，且后续流程按水平**分化**，不允许所有人走同一条固定路径。
- **用户原话（m00325）**：「本项目也要在初始确定好用户掌握程度后，对于运作流程做出区分，不要死板的走一套流程」。
- **三档初始画像**（与需求 57 的四类学习者对齐）：
  | 档位 | 对应需求 57 的人群 | 核心差异 |
  |---|---|---|
  | L1 零基础 | 核工程/物理本科生初学（主要用户） | 需要先修填补（电路/数电）→ 核电子学主干 |
  | L2 中等 | 研究生补前端电子学（其次） | 跳过先修，直接进核电子学，但需诊断具体缺口 |
  | L3 较高 | 补基础的工程师 / 考研期末备考者（以后） | 只要薄弱点与考点，不要系统讲解 |
- **差异化维度**（初定，待文献确认）：起始知识点层级、首轮用「完整样例/补全步骤/直接出题」、追问阶梯起始层级与上限、单次会话新知识点上限、反馈延迟策略。
- **不去统一的理由**：Kalyuga 团队的**专长逆转效应（expertise reversal effect）**——对新手有效的强指导，对熟手会**降低**学习效果（`D:\DeepSeek\starmap\.scratch\lit\evidence-tables.md:55`：*「样例效应：新手身上高指导优于低指导，随专长提高样例效应消失甚至反转（Chen et al. 2015；Kalyuga & Sweller 2007）」*）。单一固定流程必然在其中一档上是负效应。
- **与 D3 的关系**：D3 说「关内允许尝试—失败—再听讲解」；D12 细化的是**不同起点的人从哪一层关卡进入**，不是重复门控。
- **与 D4 的关系**：D4 的「图为主导航 + 线性退路 + 可解释推荐」是导航层；D12 是**教学策略层**的分化。

### D13｜三档模拟学习者做端到端测试与体验评估 ✅ 用户明确要求

- **决策**：建立**三个测试用子智能体**，分别扮演 L1 零基础 / L2 中等 / L3 较高，执行端到端流程并产出体验评估。
- **用户原话（m00325）**：「添加测试用子智能体，一位初学者（0基础），一位中等掌握程度，一位高等掌握程度，他们需要进行端到端的测试，并对使用体验做出评估」。
- **定位**：这是**常驻测试资产**，不是一次性调研。两个使用时机：
  1. **设计期**：对已裁决的交互方案做「学习者视角评审」，在写代码前发现「这对零基础来说太难/对熟手来说太啰嗦」。
  2. **实现后**：真正驱动浏览器走完整流程（Playwright + LLM 操作），产出结构化体验报告。
- **要求**：
  - 三档 persona 必须在**已有知识边界、典型误解、求助倾向、追问容忍度**上有实质差异，不能只写「你是初学者」。
  - 评估必须结构化（认知负荷、挫败点定位、流程卡点），禁止空泛夸奖。
  - 评估者与被评估者分离（生成侧 LLM 不能给自己打分）。
- ⚠️ 具体 persona 提示词、指标量表、脚本骨架待调研返回（见 open-questions OQ12）。

## 四、会直接进规格的数值（表 3 摘要）

| 参数 | 取值 | 依据 |
|---|---|---|
| 章末出口测通过线 | 85%，n=8 题中 ≥7 对（二项下界） | Block & Burns 1976 惯例 + 二项检验 |
| 高入度先修节点通过线 | 90%，n=10 题中 ≥9 对 | 同上，按重要性上调 |
| 每关题量 | 5–8 题 | 低于 5 题无法区分 85% 与 70% |
| 免费重试 | 1 次，**换平行题不换原题** | Bloom 1984 形成性测验—矫正—平行测验 |
| 事实/程序性题反馈 | 即时 | Kulik 1988；van der Kleij 2015 |
| 复杂概念题反馈 | 即时给「对错＋错因类别」，完整解法延迟到再试一次后 | Butler 2007 |
| 错题后变式题 | ≥2 道同结构 | Pan & Rickard 2018 |
| 错题后变式题间隔 | ≥1 天（推荐 1–3 天） | Rohrer & Taylor 2006；Cepeda 2008 |

## 五、三条最该担心的风险（写进规格的「已知弱点」）

1. **van Gog & Sweller 2015**：测试效应随元素交互性升高而减弱、极高复杂度时可能消失。核电子学题目恰恰是高元素交互性（器件＋电路＋公式＋单位），「题目关卡驱动」的地基在这个学科上**最不稳**——必须靠大量变式与即时精细化反馈补，而不是靠「多做题」。
2. **Slavin 1987 + Kulik 1990**：掌握学习在标准化测量上的真实效应约 0.2，而非流传的 0.7–2.0，且门槛会增加学习时间、降低完成率。系统可能「看起来很严谨，实际学得更少」。
3. **Chauhan 2025 + Bastani 2025**：AI 生成题无效干扰项 33.75%，无护栏 AI 在撤除后让学生**倒退 17%**。用 AI 题判定掌握＝把错误掌握写进图谱，之后所有推荐都建在错地基上。

## 三·补三｜新增裁决（D14，来自课程体系调研）

### D14｜教材分级采用「课程先修关系」为准，不采信「三本同类」的常识 ✅ 有官方大纲证据

- **来源**：`D:\DeepSeek\starmap\.scratch\mastra-research\curriculum_report.md`（206 行，7 节，全部附来源 URL）
- **核心事实（每条都有大纲原文）**：
  1. **核电子学在第 4–6 学期，3–4 学分 / 48–72 学时**，不要写死第 5 学期。兰大第 4、复旦第 4、南华第 5–6、清华第 6、华电实验课在四年级。
  2. **「数字部分 → 核电子学」是真实直接先修关系**，官方书面证据 4 条：南华先修栏「模拟、数字电子技术，原子核物理」；复旦「要求预修模拟电子技术、数字电子技术」；兰大「电子线路」（模拟+数字合并的《电子学基础》4 学分 72 学时）；南华《核技术应用概论》先修栏含「核电子学」（反向证明它也是后继课前置）。
  3. **时间差恰好 1 个学期**：数字电路第 3–4 学期 → 核电子学第 4–6 学期。分级时**数字部分必须排在核电子学之前，不能同级**。
  4. **用户「最核心的两本」分属两层**：康华光/阎石数字部分 = **D 先修基础**；王芝英核电子学 = **A 主干**。中间还隔着模拟电子技术、电路分析（李瀚荪）、原子核物理（郭江）三门。
- **章节顺序（三校完全一致，无分歧）**：信号与噪声 → 前置放大器 → 成形/滤波放大器 → 脉冲幅度分析（甄别→单道→ADC）→ 时间分析（定时/符合/TAC/TDC）→ 数据获取（定标器/计数率计/多道分析器）。
- **三个反常发现**（直接影响知识图谱的形状）：
  - **反常 1**：王芝英＝本科教材主力（兰大/南华/东华理工选用教材）；王经瑾＝多数学校只是**参考书**；**汤彬《核辐射测量原理》全书 9 章没有核电子学章**（1 核辐射基础/2 相互作用/3 统计误差/4 探测器/5 带电粒子/6 γ/7 X 荧光/8 中子/9 辐射防护），它是「探测+测量方法」书 ⇒ **不能放 A 层的核电子学主干位，会造成路径错位**。
  - **反常 2**：本科《核电子学》终点是**多道分析器**；兰大 72/南华 56/复旦 54 三份大纲最后一章都是「数据获取和处理」4–6 学时，**没有任何一份出现 FPGA、DSP、数字多道、数字脉冲处理**。数字内容只以两种形式出现：复旦第 2 章「模拟/数字电子技术相关知识（自行学习）」；上交大研究生 PHY8508 第 13–14 周「FPGA 可编程器件介绍与设计（6 学时，实验课）」。
  - **反常 3**：探测与电子学有三种组织方式并存——兰大**链式**（核电子学→核物理实验方法，后者先修栏写「核电子学和原子核物理」）、南华**并列式**（核辐射探测 C ∥ 核电子学 C，互不先修）、成都理工**合并式**（《核辐射探测器与核电子学》64 学时 = 授课 40 + 实验 24）。**美国没有对应的独立理论课**：伯克利只有 NE 104 实验课（4 units）、RPI MANE-4350（3 学分大二春）、UIUC NPRE 451 实验室课 ⇒ Leo/Knoll/Nakhostin 都不是按中国课时编排的，**找不到「课程对齐」参照物**。
- **裁决**：
  - 采用**课程先修关系**作为图谱纵向主干，不采信「三本同类」的常识分组。
  - 教材分层按证据修正两处：① `18 原子核物理实验方法` 从 D 层移到 **A/T2**（它是后继课教材，兰大大纲先修栏反向证明）；② `05 汤彬` 从 A 层的「核电子学」位移到**探测/测量方法**位（与 06 陈伯显、03/04 Knoll 同组）。
  - **标注缺口**：资源库没有「数字多道 / 数字脉冲处理」对口教材。`13 Nakhostin` 是唯一候选，但它对应的知识块在中国本科大纲里**不存在**（属研究生/科研层）。这是图谱必须显式标注的边界。
  - 复旦独有内容要保留：第 5 章「时变与非线性电路」（线性门/展宽器/堆积判弃/基线恢复）4 学时；第 9 章「仪器标准 NIM/CAMAC/VME」1 学时。
- **未找到可核验来源的两项（如实标注）**：① 任何高校核专业把**康华光数字部分**列为《数字电子技术》选用教材（只见其作电类专业教材或核专业参考书）；② 任何**本科**核专业把数字多道/FPGA/DSP 单独设课。
- ⚠️ **对 D12 的影响**：三档初始画像需要按**学期进度**对齐，而不是按「零基础/中等/高」。L1 零基础 ≈ 大二下（已修电路分析，正修/未修模拟与数字）；L2 中等 ≈ 大三上（已修数字与模拟，未修核电子学）；L3 较高 ≈ 大三下至研究生（已修核电子学，补薄弱点/考研）。
