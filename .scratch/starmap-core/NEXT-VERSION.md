## 1. 本版本对英文教材做了什么

27 本书里 13 本是英文原版。判据是可复算的一条：`content/<id>/toc.json` 的节点带
ASCII `nameOriginal`，中文书没有。按这条判据各自数出来的数量是 13 / 14，与人工清单
一一对上（`app.sources.lang` 见迁移 `apps/api/migrations/0062_sources_lang.sql`）。

| 动作 | 结果 |
|---|---|
| `sources.lang` 标注 | 14 本 `zh` / 13 本 `en` / 101 篇 `paper` |
| `sources.enabled = false`（13 本英文书） | 保留 `sources` 行留痕，不再出现在任何界面 |
| 级联删除这 13 本的知识点与切片 | `knowledge_points` 7227 → **4030**，`chunks` 96729 → **78204** |
| 删除随之变空的 `modules` | 191 个空壳（362 → **171**） |
| `content/stats` 只列 `enabled` 来源 | 来源表从 128 行降到 115 行（14 书 + 101 论文） |

被停用的 13 本（`sources.id`）：

```
nakhostin-2018      闪烁探测器信号读出

rivetti-2015        硅像素探测器前端
spieler-2005        半导体探测器

```

`content/<id>/` 下的产物（`toc.json` / `chunks.jsonl` / `edges.json`）**没有删除**，
恢复不需要重新解析 PDF，也不需要重跑 OCR。

### 恢复方式

```bash
# 1) 重新启用来源
psql "$DATABASE_URL" -c "UPDATE app.sources SET enabled = true WHERE lang = 'en';"

# 2) 逐本重新入库（走的是同一条生产管线）
pnpm --filter @starmap/api content:import --dir content/knoll-4e-2010
```

`import-content.ts` 现在有一道守卫：来源存在且 `enabled = false` 时**拒绝导入**，
除非显式加 `--force`。理由写在函数注释里 —— 停用书的产物还在磁盘上，任何批量重跑
（比如 `for d in content/*/`）都会把它们静默导回界面，而「移除」这件事没有任何地方
会报警。恢复时先 `UPDATE ... enabled = true` 就不必用 `--force`。

## 2. 推迟到下版本的具体缺陷

### 2.1 答案块误标：英文书 50.7%，中文书 14.3%（原 t46）

**根因（已定位到函数级，未修）**：`tools/ingest/classify.py` 判定「一个 chunk 是不是
答案块」时用 `MAX_FORMULA_PUNCT` 数标点密度。那个判据只数全角标点（`，。；：`），
英文散文的 `.` `,` `;` `:` 全部绕过 —— 于是英文书里成段的正文被判成公式块，再被
「公式块即答案候选」的规则连带标成答案块。

**验收判据（下版本修的时候照这个测）**：修完之后英文书的答案块占比应接近中文书的
14.3% 量级，且 `wrong_on_paper`（答案块指向的页码落在正文区）必须为 0。

**注意**：t46 在 attempt 3 一度把判据加进 `tools/ingest/`，随后按本裁定回退。若下版本
重做，先查 `git log -- tools/ingest/classify.py` 有没有残留提交。

### 2.2 译名三类缺陷（原 t45，**改动已在库里但未经评审**）

content-dev 已交付并自称修完，但独立评审席位（t54）被本裁定取消，所以这批改动**没有
经过第三方验证**，下版本必须先审再信。它声称的数字：

| 缺陷 | 改前 | 改后（严格口径） |
|---|---|---|
| A 不同原文压成同一中文名 | 53 组 / 145 节点 | 0 组 / 0 节点 |
| B 名字里嵌分节编号 | 467 | 55（全是中文原题自带的编号，译文嵌编号 0） |
| C OCR 把小节标题劈成两半 | 2 处 | 已合并（王经瑾，8 张引用表零残留） |

**口径陷阱**（content-dev 自己写在票面）：缺陷 A 必须用严格口径
（剥分节编号含 `A.8` / `B.2` / `1.6.E` 字母段 + 去冠词 + 小写 + 去空白）才得到 0 组；
宽松口径（只剥 `^\d+(\.\d+)+ `）永远剩 9–11 组，那些是同一英文标题的大小写/连字符/
单复数差异，属真同义。下版本复测看到非 0 不要误判为回归。

### 2.3 目录折行标题被拆成两个节点（原 t50，**影响中文书，未推迟**）

票面例子「作用与地位」是中文书的节点，所以这一条**没有**跟着英文书一起推迟，仍在
本版本范围内（见 t50）。写在这里只是提醒：修它的时候会同时改善英文书，但不要因为它
列在「英文教材」上下文里就一并砍掉。

## 3. 与本裁定无关但容易混淆的三件事

- **t41 答案附录识别**：15 本英文书里只有 `grupen-2e-2008` 真有答案附录（PDF p558
  `18 | Solutions`），其余 14 本没有。结论已落库（`is_answer_key` 5 → 8），随书停用
  一起从界面消失，但**这个判定是对的**，下版本恢复时不需要重做。
- **t42 译名兜底清零**：`未收录术语（…）` 从 213 → 0。产物在 `content/*/toc.json` 里
  保留，恢复时直接生效。
- **t40 页偏移与孤儿 chunk**：负页码 69 → 0、孤儿 323 → 0。同样随停用隐藏，但修法
  在代码里，恢复后仍然有效。
