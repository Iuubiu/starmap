# 13: 可解释推荐与看板页

**What to build:** 看板页告诉用户「今天该学什么」，并且**每条推荐都带理由**，用户可以拒绝并改道。

**Blocked by:** 03, 05

**Status:** ready-for-agent

- [ ] 看板页显示：今日推荐（带理由）、今日学习摘要、常用指令入口
- [ ] 每条推荐的理由是具体事实，例如「你在 A 卡住，A 依赖 B，B 你只有 32%」——不是「根据你的学习情况」这类空话
- [ ] 一键改道：用户可以拒绝当前推荐并选择别的节点，选择被记住，不反复推同一个
- [ ] 推荐理由里的数字必须来自真实掌握度，不得编造（有测试断言理由中的百分比与库里一致）
- [ ] 图谱与看板推荐同一时刻指向同一批节点，不出现两处矛盾
