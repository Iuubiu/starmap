# 03: 知识图谱地图与浏览

**What to build:** 深色画布上看得见真实的知识网络：能逐层展开、能看到自己学到哪、点一个节点就进得去；同时留一条线性主线当退路。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 画布渲染全部真实节点；在 2000+ 节点规模下拖动与缩放仍可交互（物理模拟不得阻塞主线程）
- [ ] 默认只显示当前焦点节点的两跳邻域，可 `+1 跳`／`−1 跳`／回全图
- [ ] 四种状态着色可辨：未学／在学／已掌握／需复验
- [ ] 点击节点进入对应关卡；从关卡返回时焦点保持原位
- [ ] 线性主线视图可随时切换，切换后当前位置不丢
- [ ] 缩放低于阈值时只画点不画标签，避免文字糊成一团
- [ ] 全键盘可达；图谱状态变化有非颜色的第二编码（形状或文字），不靠颜色单通道传达
