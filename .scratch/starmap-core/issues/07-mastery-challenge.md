# 07: 掌握度复验与间隔排期

**What to build:** 已掌握的微知识点会按 1/3/7/21/60 天回来找你；没通过就往下调 `current`，但 `achieved` 一动不动。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 到期的已掌握微知识点被复验抽到，每次 3–5 题，多个知识点交错出现而不是同一个连考
- [ ] 间隔按 1/3/7/21/60 天推进；通过则推进到下一个间隔，未通过则回到更早的间隔
- [ ] 未通过时按错题数量下调 `current`；`achieved` **不得**被下调
- [ ] 复验结果与普通作答共用同一套 BKT 更新路径，不另起一套算法
- [ ] 图谱上「需复验」状态与到期判定一致，不会出现图谱说有、抽考说没有
