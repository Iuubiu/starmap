# 05: 作答记录与双字段掌握度

**What to build:** 每次作答都成为证据，并算出两个百分比：`achieved`（不衰减，管解锁与成长记录）与 `current`（按半衰期衰减，管推荐与检索门控）。证据不足时如实说不足，不给假数字。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 每次作答落库并可回溯（哪道题、哪个知识点、对错、用时、第几次尝试）
- [ ] 每次作答后 BKT 后验更新；`achieved` 取历史最高，`current` 按半衰期衰减（事实 14 天／概念 30 天／综合 45 天）
- [ ] 掌握度只挂在微知识点（叶节点）上；非叶节点的颜色由子节点按证据量加权聚合得到，**是只读派生值、不落库**
- [ ] 变式数按 `variant_group` 去重计数：同组多题只算一个变式，平行题与它所平行的题共用同组因而不增加计数
- [ ] UI 双栏显示两个具体百分比；**未达 ≥3 变式且 ≥8 次作答时显示「证据不足」，不显示 0% 或任何数字**
- [ ] 属性测试覆盖三条不变量：答对不降低 `current`、答错不升高 `current`、衰减到半衰期时恰好减半
- [ ] 同一串作答输入，输出确定可重复（无隐藏随机、无当前时间泄漏）
