# 12: 三档渲染参数与流程重评

**What to build:** 同一个知识点，对零基础、有电子学基础、有工程经验三种人，首轮给的东西不一样：样例完整度、阶梯层数、会话上限、反馈延迟都不同。

**Blocked by:** 05, 10

**Status:** ready-for-agent

- [ ] P1／P2／P3 六维参数真正驱动界面与策略，不是只存在数据库里：首轮形态（完整样例／补全步骤／直接出题）、阶梯层数（3/4/5）、单次会话新知识点上限（2/3/4）、反馈延迟、每题尝试次数、判定条件
- [ ] 参数改变能被观察到：同一个知识点切到不同档位，首屏渲染结果不同（有测试）
- [ ] 每学完 3 个知识点按实际表现重评档位；升降级写进学习日志，用户能看到「为什么给我降档了」
- [ ] 档位是**每关的渲染参数**，不是三条独立的课程路径——内容与图谱不因档位而分叉
