# 11: 初始定级

**What to build:** 新用户不该一上来就考 20 题，也不该被当成零基础。用 4 题行为自评 + 8–18 道来自「马上要学的知识点池」的定级题，定出一个临时档位，并允许日后重判。

**Blocked by:** 05, 08

**Status:** ready-for-agent

- [ ] 自评只问 4 题、只问行为（最近学过什么／能不能手算某类题），不问「你觉得自己几分」
- [ ] 定级题**必须来自用户马上要学的知识点池**，不是通用题库——否则定完级学的内容和定级内容无关
- [ ] 三个停止条件都实现：后验标准差 ≤0.35 / 连续 3 题落在 40–70% 带 / 熵变化 <0.01；题量落在 8–18 之间
- [ ] 定级结果**必须展示答案与解析**，让用户能判断系统有没有把自己判错
- [ ] 定级结果是 `provisional`，学满 3 个知识点后自动重判并可升降级
- [ ] 定级过程本身不产生掌握度记录（它不是练习）
