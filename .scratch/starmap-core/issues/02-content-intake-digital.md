# 02: 内容入库 v1：康华光《数字部分》

**What to build:** 把《电子技术基础·数字部分》康华光第 5 版（559 页，资源库里**唯一**有完整文字层的主力教材）变成可用的知识图谱与可检索 chunk，并在数据库展示页里看得见。

之所以选这本书打头，不是因为它最重要——核电子学主干更靠前——而是因为它**不需要 OCR**。内容是慢的，应用骨架不能等内容。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 抽取该书的页级文本与块级版面（段落／公式／图表／表）；抽样 20 页与原书逐段对照，不漏整段
- [ ] 该书真值表与公式会把排版碎成单字符一行（已知实测现象），抽取器必须有合并策略，且合并结果经抽样核对
- [ ] 切分为 chunk；答案块按 **chunk × 微知识点** 标注进关系表（同一个 chunk 对 A 知识点是答案、对 B 知识点只是背景）；标注规则须写明并可复核
- [ ] 生成知识点候选树（学科→模块→知识点→微知识点），**每个知识点带页码溯源**
- [ ] 构建先修边：每条 `prereq` 边必须能追到证据来源（教材小节标题或课程大纲原文），**无证据的边不建**
- [ ] 产物落到 `content/` 目录并由运行时导入；数据库展示页能列出知识点数量、chunk 数量、以及任取一个知识点的来源页
