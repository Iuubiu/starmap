# 19: 课程视频下载、切片与知识点对齐

**What to build:** 从 B 站与 YouTube 下载课程视频，切成 ≤6 分钟的**纯讲解区间**片段，对齐到知识点，让用户在关卡里能直接调出对应的一段讲解。

**Blocked by:** 02, 18

**Status:** ready-for-agent

- [ ] `yt-dlp` 能从 B 站与 YouTube 下载课程视频；下载失败时记录具体原因（SSL／403／需登录），可重试
- [ ] 无可用字幕时用本地 ASR（faster-whisper）生成带时间戳的转写
- [ ] 按转写把视频切在纯讲解区间，避开寒暄、题外话、互动闲聊；片段长度 ≤6 分钟
- [ ] 每个片段对齐到至少一个知识点，能在关卡页被调出播放
- [ ] 切片结果与 ASR 时间戳一致，不存在音画与字幕错位
- [ ] **环境已知限制必须写进实现**：本机 DNS 把 `mcdn.bilivideo.cn` 解析成代理假 IP，导致 B 站纯音频流 SSL 握手失败；实现需能绕过（换 CDN 节点或走直连规则），并在失败时给出可操作提示而不是卡死
- [ ] 下载的视频与转写产物可追溯来源（原始链接、时长、下载时间），不混入无出处的素材
