# 08: 结构化智能体回合

**What to build:** 底部输入框提交一句话，屏幕中央产出的**不是气泡**，而是一张结构化产物：关卡卡、图谱聚焦、进度变化、或追问表单。历史变成学习日志。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 提交后产出的产物是四种 schema 之一（关卡卡／图谱聚焦／进度变化／追问表单），由 `packages/shared` 的 Zod schema 校验
- [ ] 页面上不存在聊天式气泡列表；历史以学习日志形式呈现
- [ ] 每轮产物渲染在屏幕中央主工作区，一次只有一张卡，新卡替换旧卡而不是往下堆
- [ ] `visibleResponse` 必须以 `?` 结尾（追问形态）或被明确标记为非追问；内部推理字段在展示前被剥离，**不得**出现在 DOM 里
- [ ] 模型返回非法 JSON 时：重试一次 → 仍失败则用 `fallbackValue` 降级为可读的错误卡，不白屏、不挂起
- [ ] 全中文：混入未加注的英文需重试或标红，且该检查进测试
