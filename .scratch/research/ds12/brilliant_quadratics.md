\#\#\# Solving Motion Equations

\#\#\# Course description

In this course\, you\'ll build visual intuition for multiplying linear terms as well as factoring quadratic expressions\. You\'ll also graph quadratic functions and learn techniques for solving quadratic equations\.

\#\#\# Topics covered

\- Multiplying linear expressions
\- Factoring quadratic expressions
\- Graphing the zeroes of a quadratic function
\- Solving quadratic equations by factoring
\- Graphing a quadratic function from vertex form
