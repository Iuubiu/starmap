# 掌握度只挂在微知识点叶节点上

掌握度只有一个真源：微知识点（叶节点）。父节点的颜色由子节点按证据量加权聚合得出，是只读派生值，不落库、不参与解锁判定。原因是一份证据只能被计权一次——如果父节点也存掌握度，同一道题会同时抬高它自己和所有祖先，解锁判定会变得不可解释。

## Consequences

- 2000+ 节点图的初始视野里大半是折叠的父节点，它们没有自己的数字，只有聚合色。点开才看到叶节点的具体百分比。
- 「整体理解某一章」这种诉求无法直接表达成分数，只能通过子节点的分布体现。
- 任何试图给父节点写入掌握度的实现都是错的，包括为了「看起来更快」而在导入时预计算并缓存进表的做法——缓存可以让它变成可重建的派生表，但不能成为解锁依据。
