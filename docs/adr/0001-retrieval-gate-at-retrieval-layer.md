# 检索门控放在检索层，不放提示词

「别在回答里给出答案」这类约束写在提示词里会随模型变强而失守——模型越有能力，越容易在学生施压下绕过措辞限制。因此答案块的屏蔽做成架构事实：每个 chunk 对每个微知识点分别标记是否为答案块，检索层按该知识点的 `current` 物理过滤，模型根本没机会看见被排除的内容。

## Consequences

- 成本从「每次调提示词」变成「标注一遍 `chunk × 微知识点`」，这是内容管线的固定工序，不是可以省掉的优化。
- 同一个 chunk 对不同知识点可以一个是答案、一个是背景，标注粒度必须按知识点，不能退化成全库布尔。
- 「不给答案」的效果可以被直接断言（集合运算），不需要靠模型行为抽样判断。
