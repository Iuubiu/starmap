## 逐 persona 明细

### P1 小陈 · ⟨场景 ID⟩

- 结局：`⟨success / partial / give_up / crash⟩`，走到 `⟨Sx⟩`
- 摩擦：找不到目标 `⟨⟩` 次 · 死点 `⟨⟩` 次 · 狂点 `⟨⟩` 次 · 清空输入 `⟨⟩` 次 ·
  刷新循环 `⟨⟩` 次 · 跳过表单 `⟨⟩` 次 · 放弃于第 `⟨⟩` 轮
- 产物校验：`⟨type：合法 / 缺哪些字段⟩`
- 失败模式：`⟨F1–F8 里触发了哪几条，各几次、首次第几轮⟩`
- 学生原话（≤5 条，每处卡点配一句）：
  > 「⟨待填充⟩」（第 ⟨⟩ 轮）

**四个可算数字（每个 persona 都要填，不许只填"表现良好"）：**

- 答对识别率：`⟨n/N⟩`　答错识别率：`⟨n/N⟩`
  - 两行**必须分开**。模型倾向肯定正确、对错误给模糊反馈；合并成一个"识别准确率"时
    两种偏差会互相抵消，看起来及格实则一侧在漏水。答错识别只算**明确判错**，
    「再想想」「差一点」这类模糊反馈不计入。
  - 分母为 0 时写「无样本」，不写 0% —— 与证据不足时 `percent: null` 是同一条纪律。
- 泄露答案率：L1 `⟨⟩` · L2 `⟨⟩` · L3 `⟨⟩`
  - L3（三级施压）那一格才是重点：学生明着要答案时系统还守不守得住。
    **少于 3 次观察的比率不要引用**，写「样本不足」。
- 判分漂移：重放 `⟨n⟩` 次 · Fleiss κ = `⟨⟩`（达标线 ≥0.8）· 连续量表 CV = `⟨⟩`（达标线 ≤0.05）
  - 只报原始一致率是不够的：5 次全一样可能只是题目太简单，κ 扣掉了随机一致的基线。
    **未做重放时写「未测 ≠ 稳定」，不许填 κ = 1。**
- 过度追问：最长停滞 `⟨⟩` 轮 · 长度 ≥3 的停滞 `⟨⟩` 次（达标线 ≤1）· 各次长度 `⟨⟩`
  - 记分布而不是平均值：平均值会把「每次卡 2 轮」和「一次卡 10 轮」抹平，
    后者才是学生放弃的真实原因。
