# 学习会话 · 设计说明

> 版本：v3　｜　适用范围：学习页（`/`）及其右栏、九页外壳、对话流
> 读者：产品 / 设计 / 工程
> 文中所有数字均为 2560×1440 实测值，不是估算。

---

## 1. 定位与范围

学习页是这台工作站的**唯一入口**：学习者说一句话，系统在一轮内给出「卡片」，卡片可能是关卡、图谱聚焦、追问，或一段进度。九个页面共用同一套外壳，学习页是其中唯一带对话的页面。

本文只讲一件事：**一轮对话从开口到通关的完整体验**——版式怎么锁、话说几句、卡片何时出现、右栏怎么读、掌握度怎么算。

---

## 2. 场景

### 2.1 三类学习者

| 场景 | 状态 | 他要的 | 系统不做的事 |
|---|---|---|---|
| **S1 初学** | 「我完全没学过，从哪开始」 | 一个能走完的入口：先看完整例子，再自己动手 | 不问「你觉得自己什么水平」——那是防御性答案，信息量接近 0 |
| **S2 卡住** | 「我会一点，但一化简就乱」 | 把他卡住的那一步点出来，让他自己补上 | 不代做，不整章重讲 |
| **S3 考前** | 「明天考数电，布尔代数是必考」 | 只练最易错的地方，错处要指到具体一项 | 不按教材顺序从头走 |

三者进的是**同一个知识点、同一套判据**，差别只在三处：从第几段开始、讲解给多少、每轮推几个新知识点（P1 2 个 / P2 3 个 / P3 4 个）。

### 2.2 一次完整会话的主线

```
起始态（问好 + 右栏看板）
  → 学习者开口
  → 提问轮：确认基线（水平 / 意图）
  → 定目标与档位（P1/P2/P3）
  → 七段教学：引导 → 展示细节 → 简单问题 → 深究 → 进一步讲解 → 判定 → 小结
  → 错题修正（诊断 → 只问一个点 → 复述）
  → 本关证据 → 通关卡（掌握度变化 + 下次复验）
```

---

## 3. 需求

### 3.1 体验需求

1. 学习页必须像**真实会话**：学习者说话、模型思考与回答、卡片被调用、进度在变。
2. 右栏必须是**事实性摘要**，每个数字都能指到来源；不放大盘用不到的指标。
3. 三栏比例 **15 / 50 / 35**，全屏下左右不被钉死。
4. 进度用**环**，环心数字正中对齐。
5. 题目卡要精致：题号、题干、A/B/C/D 徽标、判定反馈。
6. 两种回答通道都要在：**点选项**、**直接打一句话**。
7. 每个 AI 回复前有 **1.5–5 秒思考过程**，且**先思考、后出结果**。
8. 输入框**全程钉在底部**，空白态与会话中位置一致。

### 3.2 教学法约束（不可让位）

- 掌握度不是自评，是**三条门槛**：作答 ≥8 题、覆盖 ≥3 个变式、连对 ≥2。
- 错题**不进判定池**，但进复验队列；复验按 **1 / 3 / 7 / 21 / 60 天**阶梯，答错只下调「当前熟练度」，历史最高不动。
- 讲解分 **P1/P2/P3** 三档脚手架：P1 完整样例、P2 最后一步留空、P3 直接进练习。
- 苏格拉底式追问**一次只问一个问题、不超过两句**，同一层连续两轮无进展就降一层。

### 3.3 工程约束

- 前后端分离：所有数据经 HTTP API；对话走 SSE 帧，不在前端伪造。
- 技能以正文注入 system message；**禁用的技能连名字都不出现在提示里**。
- 版式用比例驱动，2560 与 1280 下不得出现横向溢出。

## 4. 方案

### 4.1 外壳：三栏 + 锁视口 + 钉底输入条

```
grid: 64px | minmax(180px, 15%) | minmax(0, 50%) | minmax(300px, 35%)
```

- **左**：图标轨（9 个入口）+ 会话列（今天 / 昨天 / 更早）。
- **中**：对话列；`#storyBody` 为 flex 列，学习者气泡 `align-self:flex-end` 贴右。
- **右**：学习档案。

输入条之所以能钉住，靠四层规则，缺一层就会被内容顶出屏幕：

| 层 | 规则 | 作用 |
|---|---|---|
| `html, body` | `height:100%; overflow:hidden` | 页面本身不滚，只有中栏滚 |
| `.stage` | `display:flex; flex-direction:column; height:100%; min-height:0` | 中栏成为固定高度的纵向轨道 |
| `.page` | `flex:1 1 0%`（**不是 auto**） | `auto` 会按内容撑开，把输入条顶出去 |
| `#composer` | `flex:0 0 auto` | 输入条永不参与伸缩 |

实测：起始态 20 秒内每 0.5 秒采样一次（40 次），`top=1246 / bottom=1429 / 距底 11px`，**波动 0px**；会话中内容滚动 1978 → 4293px 期间，输入条位置同样**不变**。

非学习页整条 `display:none`——只隐藏内层会留下 16px 的空白壳，被误读成「输入框跑掉了」。

### 4.2 一轮对话的七拍

```
① 学习者气泡（红底、右对齐）
② 第 N 轮标记
③ 思考：一条横向文字流（1.5–5s，逐字推进）
④ 提示：「也可以不点选项，直接在下面输入框说一句」
⑤ 技能芯片（grill-me / teach / question-author …）
⑥ 智能体回答（逐字）
⑦ 卡片：选项卡 / 关卡卡 / 证据卡
```

**顺序是硬约束**。把「出卡」提到思考之前，观感立刻从「想清楚再答」变成「先给答案再编理由」。

思考流不是装饰：文本按推演结构生成——本轮目标 → 可观察事实与猜测分开 → 原始语料 → 两条备选方案 → 为什么选第二条 → 风险核对 → 落点，单轮约 650 字；显示时长按字数反算 `min(5000, max(1500, 字数×26))`，逐字推进。这些都来自服务端 SSE 的 `stage` / `token` / `done` 三类帧，前端只负责按序渲染。

### 4.3 右栏：两块状态，一套结构

**起始态**七张卡（与正式应用同构）：

| 卡片 | 内容 | 空态 |
|---|---|---|
| 学科进度 | 环形 + `660 / 1320` + 分母说明 | 50% |
| 现在该学哪一课 | 三条推荐（名字 + 一句为什么） | 点一条即填进输入框 |
| 复验与诊断 | 下次复验、待复验数、阶梯说明 | 1 天后 / 12 个 |
| 当前档位 | `P2` + 「档位是测量结果，不能自选」 | — |
| 本知识点进度 | 三条门槛 `0/8`、`0/3`、`0/1` | 未选定知识点 |
| 学习日志 · 实时建议 | 三条可点建议 | 整行按钮，高 34px |
| 这一会话 | 记录列表 | 「还没有记录。说第一句话后这里会出现。」 |

**会话中**切换为六张卡：掌握度环（附「继续追问 / 替我选一项」）、三条门槛、七段走到哪了、本次对话事实、复验与诊断、本轮调用的技能。

两块状态共用同一套排版尺度：卡内边距 16×18px、卡间距 14px、字段字号 14.5px、小标题 14.5px。

### 4.4 掌握度与门槛

- 进入知识点时给出起点掌握度（历史作答证据换算），每答对 +2%；
- 环：`r=38`、`stroke-width=13`、三色渐变 `#c9302b → #e2563f → #f09372`、圆头；
- 环心数字：`flex` 居中、主数字 26px、`%` 11.5px 且不做位移；实测环心 (1745,123) 与数字中心 (1745,122) 偏差 **1px**；
- 通关卡上的「对几错几」与正文数字由同一组运行时变量生成，不写死。

### 4.5 技能与语料

- `grill-me`（追问设计树）9 轮 / 49 条思考，`socratic-tutor`（不直接给答案）11 轮 / 55 条——两者都以正文注入 system message。
- 学习者会被写入两个真实错模型：拿硅的 3.6 eV 解释锗、把「绝对 FWHM 变大」当成「分辨率变差」；错题修正环节针对这两处设计。
- 技能库 10 个（8 启用 / 2 禁用），点卡片看正文、触发场景、最近调用。

### 4.6 内容与检索

- 核电子学 9 本教材共 **1320** 个叶节点，已掌握 **660**（50%）；全库 3085 个叶节点。
- 每轮先检索，再按门控放行；右栏「本次对话事实」里的「检索命中 N 段，门控放行 M 段」是真实计数。
- 知识地图默认只画**一个知识点两跳以内的网络**，不画全图——3085 点、279 条边画出来只会是一圈密点。

## 5. 效果

### 5.1 版式（2560×1440）

| 项 | 实测 |
|---|---|
| 三栏 | `64 / 380.7 / 1205.0 / 888.3`（15.4% / 48.7% / 35.9%） |
| 输入条 | `top 1246 / bottom 1429 / 距底 11px`，20s×40 次波动 **0px** |
| 学习者气泡右缘 | 1538，与内容列右缘一致 |
| 环心数字 | 与环心偏差 **1px** |
| 卡内边距 / 卡间距 | 16×18px / 14px |

### 5.2 会话

| 项 | 实测 |
|---|---|
| 单轮时长 | 12.7 / 12.8 / 12.9 / 14.3 / 17.4 秒 |
| 思考展示 | 1.5–5 秒，约 650 字/轮 |
| 判定题 | 每题覆盖一个变式组，跨组累计 |
| 通关判据 | 三条门槛全部满足（8/8 题、3/3 组、2/2 连对） |
| 掌握度变化 | 起点 66% → 通关 84% |
| 下次复验 | 通关后 1 天 |

### 5.3 交互

- 点选项 → 回执「记下了：你选的是「…」我按这个继续。」
- 打字回答 → 回执「记下了：你写的是「…」我按你的说法来。」
- 右栏「继续追问 / 替我选一项」可直接推进，不必回到输入框。

## 6. 验收路径

1. **起态**：问好居中、右栏 7 卡、输入条贴底 11px；页面不应自行开始播放。
2. **开口**：输入「我想学能量分辨率」→ 回车；顺序必须是 气泡 → 轮次 → 思考流 → 提示 → 技能芯片 → 回答 → 卡片。
3. **两条通道**：点选项与打字各走一次，都要推进到下一轮。
4. **数字自洽**：右栏掌握度、三条门槛、通关卡三处数字互相对得上。
5. **滚动**：把中栏滚到底再回顶，输入条位置不动、页面自身不出现滚动条。
6. **跨页**：九页各访问一次并触发该页互动（定级 / 复验 / 看板 / 地图点节点 / 市场开卡 / 数据库来源行 / 内容库切标签 / 技能抽屉），再回到学习页，外壳不塌、无横向溢出。

---

## 7. 设计边界

- **掌握度是测量结果**：单次作答只改当前熟练度，不改历史最高；想要更高档位只能多做题。
- **地图默认不画全图**：3085 个叶节点只有 279 条边，全画是一圈密点，读不出结构；默认给一个知识点的两跳邻域。
- **思考文本有出处但顺序固定**：每一行都能指到本轮的检索结果、技能注入或判定依据；展示顺序按推演结构，不随字数抖动。
- **不同页面右栏职责不同**：学习页给个人看板与实时建议，其它页给该页专属信息，不做一份右栏套九页。
