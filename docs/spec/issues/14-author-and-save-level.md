# 14: 自制关卡与关卡市场保存

**What to build:** 学完一段之后，用户可以让系统把这段学习过程打包成一张关卡草稿，补全细节后保存进关卡库，并出现在市场页。

**Blocked by:** 04

**Status:** ready-for-agent

- [x] 能把一段学习过程（涉及的题、错因、讲解片段）打包为 `level.spec.json` 草稿
- [x] 草稿可编辑补全后再保存；校验不通过的草稿不能入库
- [x] 保存后的关卡出现在市场页，可被自己重新开始
- [x] 市场页明确标注这是「保存」不是「分发」——不出现分享、上传到社区这类当前不存在的动作
- [x] 自制关卡与系统预设关卡走同一套播放器与校验器
