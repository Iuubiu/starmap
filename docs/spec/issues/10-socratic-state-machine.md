# 10: 苏格拉底追问状态机与求助阶梯

**What to build:** 追问是有状态的：会升级提示、会在该放弃时放弃、会把「不知道」和「答错」当两件事处理。上限由非 LLM 的策略决定，不由模型心情决定。

**Blocked by:** 08, 09

**Status:** ready-for-agent

- [x] 5 级求助阶梯逐级递进；每轮可用到第几级由**非 LLM 的策略核心**依据可信学习者状态决定，模型无权越过
- [x] 「不知道」与「答错」用两个独立计数器；两者的降级阈值不同
- [x] 连续 3 次答不上即退出追问，改为换更小粒度重讲——**不得**无限追问，也**不得**直接给答案
- [x] 每轮只问一个问题，问完即停（不在同一轮里自问自答）
- [x] 降级后换动作而非重复同一个问题；重复同一问题被判为缺陷并有测试
- [x] 一个独立的 judge 按**拒绝原因**分类校验每轮是否越界（泄露最终数值／公式的回复占比可测量）
