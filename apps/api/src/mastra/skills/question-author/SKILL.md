# 出题与题目校验

## 出一道题之前先定三件事

不先定这三件事就出题，出出来的题一定会返工：

1. **被测的是哪个微知识点。** 一道题只测一个点。测两个点的题，
   错了也分不清是哪个点不会，掌握度更新就是噪声。
2. **答对需要哪一步推理。** 写下来。如果你的答案里出现了题干没给的量，
   这道题就不可解。
3. **学生可能怎么错。** 至少写一个具体错法（符号错、量纲错、抄错条件）。
   写不出错法的题，通常是背出来的而不是算出来的。

## 校验清单（逐条过，不跳）

- [ ] **题干自足**：不看任何外部资料，仅凭题干能解。所有用到的物理量都有数值或符号定义。
- [ ] **答案唯一**：没有「也可以」的解释空间。若确实有多个正确答案，题干必须说明。
- [ ] **每个干扰项确定是错的**：逐项问「这一项在**任何**合理解读下都是错的吗？」
      把物理上正确、只因措辞（「必须」「只能」「一定」）才被排除的选项当干扰项，
      等于把知道更多的学生判成错。这种题比没有题更有害。
- [ ] **单位齐全**：题干的量带单位；答案要求带单位或明确说明是否无量纲。
- [ ] **难度对齐**：需要一步推理 vs 需要三步，写明；不要给 P1 学习者出三步题。
- [ ] **不含解题路径**：题干不能提示用哪条公式、哪一步先算。提示属于提示阶梯，不属于题干。
- [ ] **不泄露**：题干、选项、答案解析（如果前端会展示）里都不能出现其他未做题目答案的证据。
- [ ] **数值可算**：如果题干给了数字，答案必须能手算出整数或一位小数，不要制造计算障碍。

## 答案与解析的写法

- 答案只放最终值（或最终表达式），不要放中间步骤。
- 解析可以放推理，但**解析不得进入提示词**——它和答案一样是给判分/复核用的，
  不是给正在答题的学习者看的。
- 多选题的错误选项必须是**可解释的错法**（对应上面第 3 条列出的具体错法），
  不能是随机扰动。没有解释力的干扰项等于没出。

## 反例（这些都要重写）

- 「如图所示」但图没给 → 题干不自足。
- 「用欧姆定律求……」→ 泄露了解题路径。
- 「下列说法正确的是（多选）」但没有说明有几个正确 → 答案不唯一。
- 答案给的是公式推导的中间结果 → 学习者无法判断该填哪一步。
- 三个干扰项都是正确答案旁边随手加减的数字 → 没有诊断价值。
- 「以下哪种辐射计算光子能量时可以直接套用 E=hv」把「γ 射线」当错项 ——
  γ 射线也是电磁辐射，套用没有错；真正被排除的只是「必须」这个绝对化措辞。
  干扰项本身不成立，这道题必须重写（改问「哪种不是电磁辐射」，答案才唯一）。

## 输出要求

出一道题时，连同三样一起产出：被测知识点 id、标准答案、**至少一个具名错法**
（例如「把增益当成 1 而忽略分压」）。这三样决定了这道题能不能被判分、
能不能在答错后给出有针对性的追问。只给题干和答案是半成品。
