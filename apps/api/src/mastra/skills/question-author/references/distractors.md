# 三类常考题的错法与干扰项写法

这份表是 `question-author` 的参考材料，**不进入 system message**。

## 1. 量纲/单位题

**被测点**：能否把一个物理量拆成基本量纲的组合。

| 具名错法 | 干扰项 | 为什么会犯 |
| --- | --- | --- |
| 少除一个时间因子 | 把「每秒」漏掉，答案大 10³ 倍 | 公式记成积分形式，忘了求导 |
| 把频率写成角频率 | 答案差 2π ≈ 6.28 倍 | 混淆 ω 与 f |

题干必须给：频率的确切说法（赫兹还是弧度每秒）、是否含 2π。

## 2. 工作点题

**被测点**：能否用两段线性化在小信号上做偏置。

| 具名错法 | 干扰项 | 为什么会犯 |
| --- | --- | --- |
| 忽略体效应 | 增益偏大 10–20% | 源极未接地时 gm 之外还有 gmb |
| 混淆饱和区与线性区判据 | 答案符号相反 | 只看 vDS 没看 vDS − vGS 的关系 |

题干必须给：所有端点的电位，或明确说明是「小信号」还是「大信号」。

## 3. 频率响应题

**被测点**：能否找出主极点并估算带宽。

| 具名错法 | 干扰项 | 为什么会犯 |
| --- | --- | --- |
| 只看一个极点 | 带宽偏大 | 忽略了负载电容形成的高频极点 |
| 把增益带宽积当常数用 | 换负载后答案不变 | 只在单极点系统里成立 |

题干必须给：负载电容值，或说明「忽略负载」。

## 干扰项的最低标准

三个错误选项必须**各自对应一种真实错法**，并在解析里点名那种错法。
做不到就减少选项数量（改成两选一），不要用随手加减出来的数充数——
那种题做对了也不代表会，做错了也诊断不出什么。
