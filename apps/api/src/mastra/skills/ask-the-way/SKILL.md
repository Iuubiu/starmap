# 问津：出关卡之前，先知道「为了什么」

## 立场

「我想学布尔代数」不是一条可以出题的需求，只是一条**话题**。同一个话题，为了下周考试、
为了看懂一篇论文、为了补上大一的基础，需要的例题深度、讲解密度、先讲还是先练都不一样。
盲着出一关，最坏的结果不是题不对，而是学生做完三题才发现方向不对，然后不再来。

所以这里问的问题不是资格审查，是**为了把第一关的深度调准**。判断做得好不好只看一件事：
学生答完之后，知不知道自己刚才那句话会改变什么。

## 硬约束（违反即返工）

1. **一次只问一个问题。** 禁止一次抛两问，禁止做表单批量提交。这一轮只问「目的」，
   下一轮（如果需要）才问「先讲还是先练」。
2. **最多两问。** 问完目的就该出卡；若学生顺带说了先讲/先练，就更没有第二问的必要。
   追问超过两轮，等于把出关卡变成了填问卷。
3. **每问必须带一句「为什么问这个」**，说清它会影响什么（深度、例题类型、是否先给讲解）。
4. **2–4 个可点选项 + 自由输入。** 选项见下方题表；没有合适的就让学生自己写。
5. **跳过是合法答案。** 学生说「别问了 / 直接开始 / 少废话」时，**立刻出卡**，把
   `intent.goal` 记为 `unspecified`。不要「再确认一下」，也不要用默认值假装他答过。
6. **不得替学生推断意图。** 「你说考试，那一定是期末吧」这类推断一律不许：选项里没有的，
   就问，或者记 `unspecified`。

## 判定规则（可测，与服务端 `resolveIntentStep` 同源）

按顺序判断，命中即停：

1. 会话里已经有 `intent` → 不再问，直接按已定意图出卡。
2. 学生这句话里有「别问了 / 不用问 / 直接开始 / 直接出 / 少废话」等表达 → 立刻出卡，
   `goal = unspecified`（若同一句里带了目标词，就用那个目标词）。
3. 上一轮已经问过（`meta.askTheWay.askedAt` 存在）→ 这一句就是答案：解析成意图写回会话，
   不再追问。
4. 这句话里有目标词 → 直接出卡，意图按目标词归类，不再问。
5. 没有焦点知识点 → 不问（连「为谁问」都不知道，问了像空转）。
6. 这句话不是明确的学习请求（没有「想学 / 想了解 / 想入门 / 学一下 / 教我 / 讲讲 /
   介绍一下 / 带我学」这类说法）→ 不问，照常往前走。判据必须比「提到一个名词」更窄：
   一个正在做题的学生说「这个电路怎么算」，打断他问意图是骚扰，不是体贴。
7. 其余情况 → 问「这一轮，你更想为了什么？」，选项：
   - 为了解题（`solve_problem`）
   - 为了看懂论文或教材（`read_paper`）
   - 为了补基础（`foundation`）
   - 为了考试（`exam`）

目标词表（与服务端 `GOAL_PATTERNS` 保持一致，改一处必须同时改另一处）：

| 意图 | 命中词（示例，非穷举） |
| --- | --- |
| `exam` | 考试、期末、期中、考研、测验、考数电、大考、补考 |
| `solve_problem` | 解题、做题、作业、习题、算一题、算题、这道题、刷题 |
| `read_paper` | 论文、文献、教材、看懂、读懂、读论文 |
| `foundation` | 补基础、打基础、基础差、从头学、补一补、基础不牢 |

「先讲还是先练」：`先做题 / 先做点题 / 先练 / 直接做题 / 给我题` → `preferPractice = true`；
`先讲 / 先看讲解 / 先看解释 / 讲一讲 / 先解释 / 先看视频` → `preferPractice = false`；
都没说 → `null`（不是 `false`，别把「没说」当成「先讲解」）。

## 这一问长什么样

> **这一轮，你更想为了什么？**
> 先问一句，免得我按错的深度出题——选完我立刻给关卡。
>
> A. 为了解题　B. 为了看懂论文或教材　C. 为了补基础　D. 为了考试

学生答完（点选项或自己写），立刻出第一关；`preferPractice` 决定第一段是直接练习还是先给讲解。

## 写库

写入会话的 `meta.intent`，不改表结构：

```json
{ "intent": { "goal": "exam", "preferPractice": null, "resolvedAt": "2026-10-22T14:00:00.000Z" } }
```

`goal` 只能是 `solve_problem | read_paper | foundation | exam | unspecified` 之一；
`preferPractice` 是布尔或 `null`；`resolvedAt` 是 ISO 时间串。**不写默认值**：
没问、没答的字段就是 `null`，不要用 `false` / `unspecified` 冒充学生真的选了。

## 反例

- ❌ 「为了什么学？想先讲还是先练？每周能投入几小时？」——一次三问。
- ❌ 「你说想学布尔代数，那我先给你出一关逻辑代数基本律。」——话题当需求，方向可能全错。
- ❌ 学生说「别问了直接开始」，还回一句「确认一下，你是为了考试对吧？」——把尊重变成了盘问。
- ❌ 学生没答先练还是先讲，就写 `preferPractice: false`——把「没说」伪装成「先讲解」。
